# Shivani's AI ChatBot

An AI-powered conversational chatbot built with **Python, Streamlit, and Groq API**.

## 🌐 Live Demo

[Launch Shivani's AI ChatBot](https://shivani-ai-chatbot.onrender.com)

## 📌 Overview

Shivani's AI ChatBot is a web-based conversational AI application that allows users to interact with an AI assistant through a clean and custom-designed chat interface.

The application uses the **Groq API** to generate AI-powered responses and maintains conversation history during the active session.

## ✨ Features

- AI-powered conversational responses
- Session-based chat history
- Custom chatbot interface
- Fast responses using Groq API
- Secure API key management
- Responsive web interface
- Cloud deployment using Render

## 🏗️ Application Architecture

```text
User
 ↓
Streamlit UI
 ↓
Python (app.py)
 ↓
Groq API
 ↓
AI Response
 ↓
Chat Interface

The user sends a message through the Streamlit interface. The Python application processes the request and communicates with the Groq API to generate an AI response. The generated response is then displayed in the chat interface.
